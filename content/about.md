## 关于我

一名写代码的普通人。白天做后端，晚上折腾自己的项目。这里记录我在 **Python、Web 开发与 AI 应用**上的实践、踩坑和思考。

我不相信「看一遍就会」，所以这里的文章大多来自真实项目：能跑起来的代码、量过的数据、踩过的坑。写得慢，但每一篇都自己验证过。

## 关于这个站

这个博客是用 Python 写的，没有用任何博客框架：

| 层 | 选型 | 原因 |
| --- | --- | --- |
| Web 框架 | FastHTML | HTML 即函数，不需要模板引擎 |
| 数据库 | SQLite（fastlite） | 单文件、零运维、备份就是复制文件 |
| 正文渲染 | python-markdown + Pygments | 服务端渲染，首屏无闪烁 |
| 部署 | Cloudflare Pages | 全站静态导出，CDN 分发，零成本 |

文章源文件是 `content/posts/` 下的 Markdown，改一个字重新导入即可，不需要后台富文本编辑器。

## 关于内容

- 以**技术笔记**为主，偶尔写点工具和方法论
- 不写没验证过的东西，不写纯转载
- 代码示例尽量完整可运行，而不是伪代码
